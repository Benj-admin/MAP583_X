# Deep Learning: From Theory to Practice

Practical assignments from a Deep Learning course (MAP583, École Polytechnique — based on the [dataflowr](https://dataflowr.github.io/website/) material), implemented in PyTorch.

## Contents

| Notebook | Topic |
|---|---|
| [TP00](TP/TP00_Python_warmup.ipynb) | Python warm-up |
| [TP01](TP/TP01_MLP_vs_toy_dataset.ipynb) | MLP on a toy dataset |
| [TP02](TP/TP02_Full_training_loop.ipynb) | Writing a full training loop |
| [TP03](TP/TP03_optimization_algorithms.ipynb) | Optimization algorithms (SGD, momentum, Adam…) |
| [TP04](TP/TP04_Convolutional_networks.ipynb) | Convolutional networks |
| [TP05](TP/TP05_predictions_RNN.ipynb) | Sequence prediction with RNNs |
| [TP06](TP/TP06_stability_robustness.ipynb) | Stability and robustness of training |
| [TP07](TP/TP07_Language_modeling.ipynb) | Language modeling |

The [Lesson/](Lesson/) folder contains complementary notebooks on RNNs and packed sequences.
